Бот расписания СПК

Следит за изменениями расписания Сургутского политехнического колледжа и присылает уведомления в беседу группы — картинкой с таблицей, а не текстом.

Возможности

Что умеет бот

Минимум действий от пользователя — максимум автоматизации.

Автоматический мониторинг

Следит за расписанием вашей группы по расписанию окон — от рассвета до позднего вечера, семь дней в неделю.

Картинка вместо текста

Расписание отрисовывается как таблица на PNG — так же, как на сайте колледжа. Привычно, компактно, читаемо с телефона.

Точные уведомления

Замена преподавателя, кабинета, отмена пары, дистант — изменившаяся пара подсвечивается в таблице.

Массовые изменения

Если поменялось больше половины пар — бот присылает полное расписание дня или всей недели, а не список правок.

Автообъявление недели

Как только колледж выложит расписание следующей недели — бот отправит его картинкой один раз.

Команды в чате

/today, /week, /nextweek и админ-команды — прямо в беседе группы. Никаких приложений.

Как это работает

От запроса к API до картинки в чате

Восемь модулей, каждый отвечает за своё. Никакой магии — только Python, SQLite и Pillow.

  1. 01

    Справочники

    Бот загружает с сайта колледжа список групп, преподавателей, дисциплин и аудиторий. Кэширует в SQLite на сутки.

  2. 02

    Проверка

    По расписанию окон запрашивает расписание нужных дат и сравнивает снимок с предыдущим.

  3. 03

    Сравнение

    comparator.py находит изменения: добавленные, удалённые, изменённые пары. Определяет «массовость».

  4. 04

    Рендер

    renderer.py рисует PNG-таблицу на день или неделю (Пн–Сб). Изменённые пары подсвечиваются.

  5. 05

    Загрузка

    Картинка загружается в VK через photos.getMessagesUploadServer и получает attachment.

  6. 06

    Отправка

    Сообщение с подписью и картинкой уходит в беседу группы. При ошибке — текстовый fallback.

Полный список модулей и их ответственностей — в README.

Команды

Что можно написать боту

Публичные команды доступны всем, админские — только из ADMIN_USER_IDS.

Публичные

/start
Приветствие и краткая инструкция
/where
Какая группа сейчас отслеживается
/today
Расписание на сегодня картинкой
/tomorrow
Расписание на завтра картинкой
/week
Текущая неделя (Пн–Сб) картинкой
/nextweek
Следующая неделя картинкой
/whoami
Ваш from_id и peer_id

Админские

/group СП-4 419
Задать группу и подразделение
/interval 30
Интервал проверки в минутах
/status
Что настроено и когда последняя проверка
/test
Тестовое уведомление + расписание
/metrics
Счётчики проверок, уведомлений, ошибок
/subscribers
Кто получает уведомления
/week_skip [дата]
Не объявлять неделю автоматически
/unsubscribe
Сбросить настройки

Бот молчит на обычный текст. Реагирует только на сообщения, начинающиеся с /.

Установка

От нуля до работающего бота

Нужны Python 3.13+ и права администратора в сообществе ВК.

1

Создайте сообщество ВК

Откройте vk.com/groups, создайте сообщество. Управление → Работа с API → Создать ключ.

Права: Управление сообществом, Сообщения сообщества, Фотографии сообщества. Включите Long Poll API и отметьте «Входящие сообщения».

2

Клонируйте репозиторий

git clone https://github.com/spkh-design/Syllabus.git
        cd Syllabus
3

Создайте .env

Скопируйте пример и заполните своими значениями:

cp .env.example .env
  • VK_TOKEN — токен из шага 1
  • VK_GROUP_ID — ID сообщества (число из vk.com/clubXXXXXXXX)
  • ADMIN_USER_IDS — ваш VK ID (узнать командой /whoami)
  • ADMIN_PEER_ID — чат для служебных сообщений (опционально)
4

Установите зависимости

pip install -r requirements.txt

Если шрифты из assets/ отсутствуют — скачайте их (Noto Sans Regular/Bold + Noto Emoji). Без них таблица не отрисуется корректно.

5

Запустите бота

python bot.py

Бот начнёт long-polling и фоновый цикл проверки расписания.

Развёртывание

В облаке — за пару минут

Пример для Bothost, но подход тот же для любого хостинга с Docker.

Переменные окружения

Задайте VK_TOKEN, VK_GROUP_ID, ADMIN_USER_IDS, TZ=Asia/Yekaterinburg и DB_PATH=/app/data/bot.db.

Persistent volume

Смонтируйте постоянное хранилище на /app/data/ — там лежат БД и кэш PNG недель. Без volume настройки будут сбрасываться.

Автодеплой

git push → хостинг пересобирает контейнер и перезапускает бота. Всё через Dockerfile в репозитории.
